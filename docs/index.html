What changes

  • Price — the doc fee ($2,805) and the electronic filing fee ($245) are added to the listed price everywhere it appears: search results, the vehicle page header and the Details table.
  • Disclaimer — on both pages, “Dealer fees included” opens a small panel: “Dealer fees included in price”, the doc fee and electronic filing fee, then the optional products listed separately as “Optional, not included”.
  • Wordmark and type — the whole mockup, Current and Proposed alike, is set in McLaren Sans, so Current differs from Proposed only in the fees and the new McLaren Charlotte wordmark.
  • How it opens — on a computer it opens on hover and stays open on click. On a phone it opens on tap, because phones have no hover.

Open questions for the dealership

  1. Exotic Care price. The $1,995 shown is a sample figure for the mockup. Please send the real price, or wording such as “Varies — ask your advisor” if it isn’t fixed.
  2. Disclaimer wording. The small print in the panel is sample text written for the mockup. Please confirm it or send your exact legal wording.
  3. Are the fees added on top of today’s prices? The mockup assumes yes, e.g. $431,470 becomes $434,520. If the current prices already include them, only the note and the breakdown are added.
  4. Which vehicles? All new inventory including Rolls-Royce and Koenigsegg, and pre-owned too?
  5. Vehicles without a price (“Call for price”) show no link and no disclaimer.
  6. E-Price, finance calculator and lead emails should use the same fee-inclusive figure, so a customer never sees two different prices.

Use the Current / Proposed switch at the bottom of each page to flip between the two at the same scroll position. All Inventory, New Inventory and every vehicle card lead to the mockup pages; other links and forms are disabled.
